Para agregar la próxima actividad:

Copiar uno de los bloques <a class="island island--main">...</a> dentro de <nav class="islands-grid">, cambiar el emoji, el texto y el href. 
La grilla se reordena sola — no hay que tocar CSS ni recalcular anchos. 
Dejé al final un bloque "Muy pronto" a modo de plantilla (con 🔒) que podés convertir en actividad activa cuando corresponda, o duplicar para mostrar más juegos bloqueados.

Otros detalles del rediseño:

Los íconos ahora rotan entre 4 colores (coral, uva, mostaza, verde) según su posición en la grilla, para que un tablero con muchas islas no se vea monocromático.
Si algún día hay tantas actividades que no entran verticalmente, el panel del tablero tiene scroll propio con una barra fina y clara — el resto de la pantalla (cielo, mascota, título) queda fijo.
Las tarjetas "Bingo" usan el mismo emoji del juego base más una insignia 🎯 en la esquina, para distinguir el modo sin inventar un ícono nuevo.
