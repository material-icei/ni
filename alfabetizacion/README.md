Albafetización: 60 ejercicios en total (10 por actividad).

Qué incluye:

Letra inicial/contiene/final: letra grande + una "forma de palabra" con casillas resaltadas (inicio/medio/final) para indicar la posición sin usar texto, y 3 opciones con emoji.
Completar inicial / final / vocales: emoji + palabra en casillas con un espacio en blanco, y 3 letras para elegir.
Rimas: emoji base + 3 opciones, usando pares que realmente riman (pato-gato, dado-helado, foto-moto, sol-caracol, pez-nuez).
Intruso: 4 elementos mezclando letras, números y emojis; se toca el diferente.
Sistema de recompensa: estrella solo en el primer intento correcto, la opción errónea se apaga (no avanza), y al final medalla 🏆/🥈/🥉 con confeti.
Estrellas y puntitos de progreso propios por actividad, escenario 16:9 sin scroll ajustado dinámicamente para Chromebook.

Para agregar más letras al set de consonantes, hay que sumar ejercicios nuevos al array correspondiente en script.js
